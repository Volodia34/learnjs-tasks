# Task: Which values does the while loop show?

### **📝 Task Details**

* **Original Task:** [Which values does the while loop show?](https://javascript.info/while-for#which-values-does-the-while-loop-show)
* **Importance:** 4

For every loop iteration, write down which value it outputs and then compare it with the solution.

**Question:** Both loops alert the same values, or not?

#### 1. The prefix form `++i`:
```javascript
let i = 0;
while (++i < 5) alert( i );
```

#### 2. The postfix form i++:

```javascript
let i = 0;
while (i++ < 5) alert( i );
```
